# inventaire.cloud

A free and simple inventory tool for professionals and individuals, available at [inventaire.cloud](https://inventaire.cloud).

Create an inventory from scratch with your own typed columns, or start from a ready-made template (bar, wardrobe, IT equipment, home insurance…). Export it to Excel, CSV and more, connect it to other tools through the API, and produce an official PDF that can be signed electronically.
